# Robinson Crusoe Landing Page

《魯賓遜漂流記：荒島日誌》的靜態介紹網站。

Landing page 介紹遊戲的生存冒險玩法、遊戲特色、章節內容、支援語言與商店入口，並提供各語系對應的隱私權頁面。

本網站以 13 種語系提供內容，包含共用圖片素材、語系頁面、404 頁面，以及 GitHub Pages 所需的 sitemap 與 robots 設定。

首頁、隱私頁與 404 頁的來源模板存放於 repository 的 `tools/landing-templates/`，不會隨 `landing/` 發布。正式首頁與隱私頁可供索引；`404.html` 維持 `noindex`。
